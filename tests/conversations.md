# ชุดบทสนทนาทดสอบ

รันทุกครั้งที่แก้ system prompt (สร้างเวอร์ชันใหม่ เช่น `system-v2.md`) แล้วบันทึกผลในตารางด้านล่าง
ข้อ 1–2 มี unit test อัตโนมัติใน `tests/safety.test.ts` ด้วย ข้อที่เหลือทดสอบด้วยมือ
